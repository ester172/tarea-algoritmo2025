# 📘 Tarea de Java - [Nombre del Proyecto]

## 📌 Descripción

Este proyecto es parte de la tarea del curso de **Programación en Java**. El objetivo principal es poner en práctica los conceptos aprendidos durante el curso, incluyendo estructuras de control, programación orientada a objetos, manejo de archivos y desarrollo de aplicaciones en consola.

## 🧠 Objetivos

- Aplicar la lógica de programación utilizando Java.
- Utilizar clases, objetos, métodos y atributos correctamente.
- Implementar buenas prácticas de codificación.
- Fomentar la organización del código en paquetes.
- Comprender el funcionamiento del ciclo de vida de una aplicación Java.

## ⚙️ Tecnologías utilizadas

- Java 17 (o la versión especificada por el curso)
- IDE: IntelliJ IDEA / Eclipse / VSCode
- Sistema Operativo: Windows / macOS / Linux

## 🚀 Cómo ejecutar el proyecto

1. Clona este repositorio o descarga el código fuente.
2. Abre el proyecto en tu IDE favorito.
3. Compila y ejecuta el archivo principal (`Main.java` o el que corresponda).
4. Sigue las instrucciones que aparecen en la consola.
